# MoveX Digital website

Static multi-page website for MoveX Digital. The production site is deployed from the `main` branch with GitHub Pages Actions.

## Update the website

1. Edit the pages and assets in the repository root.
2. Commit and push changes to `main`.
3. The `Deploy static site to GitHub Pages` workflow publishes the update automatically.

The site is built from the static HTML and `assets/` folder; no build step or package installation is required.
